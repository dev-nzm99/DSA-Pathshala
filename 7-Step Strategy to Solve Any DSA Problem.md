# 7-Step Strategy to Solve Any LeetCode DSA Problem

## 1. Understand the Problem
- Read the question carefully.  
- Identify the input, output, and constraints.  
- Make sure you fully understand what the problem is asking.

**Ask yourself:**
- “What exactly do they want?”
- “Can I explain the problem in my own words?”

---

## 2. Devise a Strategy (Find Edge Cases)
- Think of an approach: start with brute force, then consider optimizations.  
- Identify possible edge cases:
  - Empty input  
  - Single element  
  - Negative values  
  - Very large input  
  - Duplicate values  

**Ask yourself:**
- “How would I solve this manually?”
- “What unusual cases could break the solution?”

---

## 3. Break Down the Problem
- If the problem is complex, divide it into smaller steps.  
- Solving smaller parts makes the entire problem easier.

---

## 4. Write a Pseudocode
Write the logic in simple steps before coding.

Example:

```
set answer to 0
for each number in array:
    add number to answer
return answer
```

Pseudocode helps you avoid confusion during implementation.

---

## 5. Implement the Solution
- Convert the pseudocode into actual code.  
- Keep your code clean and readable.

---

## 6. Testing and Debugging
- Test using sample inputs.  
- Test edge cases.  
- Test custom cases that might break the logic.  
- Fix bugs and validate again.

---

## 7. Optimize and Review
- Analyze time and space complexity.  
- See if the solution can be improved.  
- Review code for clarity and efficiency.

**Ask yourself:**
- “Is this the most optimized solution?”
- “Will this pass all constraints?”

---

## Summary
This 7-step process ensures a clean, structured, and optimized way to solve any DSA problem:
1. Understand  
2. Strategy + Edge Cases  
3. Breakdown  
4. Pseudocode  
5. Implement  
6. Test  
7. Optimize
